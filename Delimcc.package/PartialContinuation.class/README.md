I am a slice of a call stack, the contexts that a capture cut off the stack down to a delimiter of my #prompt, a DelimccPrompt. The capture cuts my bottom context off its sender, so I do not hold the stack below the delimiter. Use me like a block with #value or #value:, or with #pushSubCont:, which evaluate a copy of my contexts on top of the current call stack: each invocation copies them, so I can be invoked many times.
