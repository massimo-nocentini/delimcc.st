I am signalled by the first invocation of a `PartialContinuation`, or by its `#unwind`, when its contexts have been resumed since its capture, before it took them: by a `Continuation` captured inside the delimiter before the capture, which holds the bottom part of the same contexts, and whose invocation has resumed them.

Running them, or making the template from them, would run what that computation has left of them, or a copy of the whole stack below the delimiter. The continuation stays in this state: every later invocation signals me too.
